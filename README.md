# Лабораторна робота №1: Апроксимація функцій методами інтерполяції та МНК

**Варіант завдання:** №20  
**Базові точки (5 вузлів):** `(-3, -2.1), (-1, -0.8), (1, 0.9), (3, 2.2), (5, 3.1)`  
**Стек технологій:** 
- **Мова:** TypeScript (строга типізація даних Point, Metrics, Viewport).
- **UI Фреймворк:** React 19 (компонентний підхід, хуки стану, мемоізація розрахунків).
- **Математичні обчислення:** `ml-matrix` (стійкий QR-розклад на базі Householder reflections).
- **Стилізація:** Tailwind CSS 3 (мінімалістичний Senior UI/UX у стилі shadcn/ui, палітра `zinc-950`).
- **Графіка та анімація:** HTML5 Canvas API (Retina HiDPI, матові лінії без паразитного світіння, requestAnimationFrame, автоматичне масштабування осей).

--- 

## 🚀 Інструкція із запуску

### Варіант 1: Відкриття у браузері безпосередньо
Просто відкрийте файл `index.html` у будь-якому сучасному веб-браузері (Chrome, Firefox, Edge, Safari).

### Варіант 2: Запуск локального сервера розробки
```bash

npm run dev

npm run build

```
Після запуску відкрийте у браузері адресу: [http://localhost:3000](http://localhost:3000).
